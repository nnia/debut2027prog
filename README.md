# debutprog.ru — лендинг конкурса «Дебют юного программиста 2026»

Одностраничный сайт-визитка для конкурса программных проектов «Дебют юного программиста 2026», проводимого в рамках Открытого Санкт-Петербургского фестиваля информационных технологий «В Аничковом» (ГБНОУ «СПб ГДТЮ», отдел техники).

## Состав архива

```
debutprog/
├── index.html              # единственная HTML-страница (15 секций)
├── styles.css              # стили (mobile-first, ~1600 строк)
├── content.js              # подстановка дат, контактов и ссылок из JSON
├── script.js               # ванильный JS: меню, FAQ, плавная прокрутка, версия для слабовидящих
├── data/
│   └── site.json           # редактируемые даты, контакты, ссылки, оргкомитет, документы
├── debut2026_logo.svg      # логотип конкурса
└── README.md               # этот файл
```

Внешних зависимостей нет: ни npm, ни сборщиков, ни CDN-скриптов. Шрифты подключены через Google Fonts (Roboto, Jost, JetBrains Mono); если нужна полная автономность — скачайте их и положите рядом, поправьте `@font-face` в `styles.css`.

## Локальный запуск

Контент подгружается из `data/site.json` через `fetch`, поэтому нужен **локальный HTTP-сервер** (при открытии `index.html` как файла JSON не загрузится, на странице останутся значения из HTML-заглушек).

```bash
cd debutprog
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Редактирование контента

**Главный файл:** `data/site.json`.

| Раздел JSON | Что менять |
|-------------|------------|
| `year`, `contest` | Год конкурса, заголовки страницы |
| `links` | Форма регистрации, anichkov.ru, PDF положения, карты |
| `dates` | Сроки этапов, дедлайн заявок, финал, итоги |
| `venue` | Адрес, карта |
| `contacts` | E-mail, телефоны, состав оргкомитета |
| `documents` | Список PDF в секции «Документы» |
| `snippets` | Тексты с подстановками `{{dates.final.display}}` и т.п. |

После правки JSON обновите страницу в браузере (Ctrl+F5). Деплой — залить папку целиком, включая `data/site.json` и `content.js`.

**Если оргкомитет или документы пустые:** откройте DevTools → вкладка Network → обновите страницу. Запрос `site.json` должен быть со статусом **200**. Если **404** или ошибка CORS — сервер запущен не из папки `debutprog`, или страница открыта как `file://` (так нельзя). Запускайте: `cd debutprog && python3 -m http.server 8000`.

Длинные тексты (номинации, FAQ, критерии) по-прежнему в `index.html`. При смене года обновите также год в `debut2026_logo.svg`, если меняете файл логотипа.

## Деплой на debutprog.ru

Сайт статический — поднимается на любом хостинге, обслуживающем статику:

- залить содержимое папки `debutprog/` в корень `public_html` через FTP/SFTP
- либо положить в Netlify / Cloudflare Pages / GitHub Pages — drag-and-drop, без настройки билда
- nginx: `root /var/www/debutprog;` и `index index.html;`

## Адаптивность

Mobile-first, breakpoints: 640px / 960px / 1280px. Проверено на ширинах от 360px до 1440px+.

## Версия для слабовидящих

В шапке справа — кнопка «Версия для слабовидящих». Открывает панель с настройками:

- 3 размера шрифта (А / А+ / А++)
- 4 цветовые темы: обычная / чёрным по белому / белым по чёрному / бежевая
- увеличенный межбуквенный интервал
- скрытие изображений
- системный шрифт (Arial)
- сброс настроек

Для боевого запуска включите сохранение состояния. В `script.js` есть функция `loadA11yState()` с TODO-комментарием — там же шаблон для cookie-варианта (cookie работают без согласия пользователя, если строго функциональные и не отправляют данные третьим лицам, что соответствует GDPR/152-ФЗ для технических cookie). ## Контент

Даты, контакты, ссылки и оргкомитет вынесены в `data/site.json` (см. раздел «Редактирование контента»). Остальной текст страницы взяты из:

- информационного письма конкурса 2026
- Положения об открытом Санкт-Петербургском фестивале «В Аничковом» (2025, утверждено 01.09.2025)
- пригласительного письма

Ссылки на форму регистрации, e-mail, телефоны и адрес проверены и совпадают с источниками. Ссылки на полные PDF-документы в секции «Документы» ведут на сайт `anichkov.ru` — заменить на точные URL после публикации документов 2026 года на сайте организатора.

## Что подправить перед публикацией

1. В секции «Документы» — заменить ссылки-заглушки на актуальные URL документов 2026 года на anichkov.ru.
2. В `script.js` — раскомментировать/добавить персистентность настроек версии для слабовидящих (см. выше).
3. Опционально — добавить `<meta property="og:image">` с превью для соцсетей и `favicon.ico`.
4. Если нужна аналитика — Яндекс.Метрика / Plausible подключаются в `<head>` одной строкой.
